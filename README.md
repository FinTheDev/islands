# Islands

A voxel sandbox game built from scratch in Python using Pyglet and OpenGL.

## Goals

- Learn low-level graphics programming
- Implement a voxel-based world
- Procedural island generation
- Basic physics and interaction
- Expand into a fully playable sandbox experience

## Tech Stack

- Python 3
- Pyglet
- OpenGL

## Status

Early development.

## Running

```bash
pip install pyglet
python -m src.main
```
